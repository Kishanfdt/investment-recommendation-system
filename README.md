AI-Powered Investment Recommendation System | React, FastAPI, Supabase, Python (Scikit-learn, XGBoost, LightGBM, TensorFlow), SHAP, LIME

Architected and built a full-stack AI-driven investment platform for NIFTY equities (RELIANCE, TCS, HDFC Bank, Infosys), integrating React frontend, FastAPI backend, and Supabase for real-time data management and investor risk profiling
Designed and implemented an 11-stage machine learning pipeline combining Random Forest, XGBoost, LightGBM, and LSTM models with a unified feature configuration layer, ensuring consistency and reusability across all platform modules
Applied explainable AI techniques (SHAP, LIME) to interpret model predictions and generate transparent, trust-building investment recommendations for end users
Engineered risk-profiling logic to personalize recommendations based on individual investor risk tolerance, improving relevance and decision-support quality
